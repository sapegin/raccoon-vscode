# Git Navigator

Navigate unstaged Git changes across files in VS Code’s single-file diff editor. At the first or last change in a file, jumps to the adjacent changed file.

## Ignored files

`gitNavigator.ignoredFiles` excludes file names or repository-relative paths. Lock files are ignored by default.

## Commands

| Title | Command | macOS shortcut |
| --- | --- | --- |
| Git Navigator: Go to Next Change | `gitNavigator.nextChange` | `Cmd+Shift+Down` |
| Git Navigator: Go to Previous Change | `gitNavigator.previousChange` | `Cmd+Shift+Up` |
